# Modern Software Engineering (Farley)

Binding engineering guideline. When this skill triggers, read the full text and follow it:

**Read `docs/guidelines/modern-software-engineering.md` and apply its rules to the current work.**

Core lens: be an expert at learning (small iterative steps, fast feedback, treat changes as hypotheses) and at managing complexity (modularity, cohesion, separation of concerns, abstraction, loose coupling). Let testability and deployability drive design; let evidence decide.
