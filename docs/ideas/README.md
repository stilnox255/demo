# Ideas

Rough notes that are not ready to be an epic. Captured by the `/capture-idea` skill,
one file per idea, deleted when the idea is promoted or dropped.

Deliberately unnumbered: a number would be reused by the next capture after a deletion
and then mean two different things.

An idea has no ADRs, no GitHub issue and no roadmap entry. It is a placeholder for a
conversation, and the point of keeping it here rather than in a chat log is that it can
be found by grep.
