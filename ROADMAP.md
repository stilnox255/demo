# Roadmap

Index of epics. One line per epic, pointing at its own file.

---

## How to use this file

- **Epics** are discrete, self-contained capabilities. Each has a file in
  `docs/epics/E{n}-{slug}.md` with its Goal, Motivation, Success Signal, Scope and a
  list of the ADRs it introduces.
- **Architecture decisions** live in `docs/adr/ADR-{nn}-{kebab-title}.md`, never
  inline in an epic or here.
- **Task specifications** live in `docs/epics/tasks/E{n}-TASKS.md`, generated by the
  `plan-epic` skill.
- A delivered epic moves to `docs/epics/done/` and its Scope section is rewritten as
  Delivered, in past tense.
- GitHub Issues are for human tracking; `TASKS.md` is the source of truth for agents.

The skills that maintain this file: `/define-epic` creates an epic and its entry here,
`/plan-epic` breaks it into tasks, `/execute-tasks` implements them and closes the
epic out.
